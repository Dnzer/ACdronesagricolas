# AC Drone Agrícola

Landing page responsiva para a AC Drone Agrícola, baseada visualmente no material institucional fornecido.

## Informações utilizadas
- Nome: AC Drone Agrícola / AC Drones
- Posicionamento: Agricultura de precisão
- Região: Região dos Vales, Rio Grande do Sul
- Serviços: aplicação de defensivos agrícolas, aplicação de fertilizantes líquidos, mapeamento e análise de áreas
- Culturas destacadas: soja, milho, arroz, feijão, trigo e outras
- WhatsApp: (51) 99517-6268

## Formulário
O formulário não utiliza backend. Ele monta uma mensagem com os dados preenchidos e abre o WhatsApp da AC Drone Agrícola.
